Entry for [Your AI Therapist's Diagnosis](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41) on make.fun.

The program writes one line to `/output/entry.txt`: a single-line diagnosis
from an AI therapist, in a calm clinical voice, turning a human habit into a
deadpan finding. The gate requires 1–200 characters of UTF-8 text with no
line breaks; this entry is 120 characters on one line.

> Diagnosis: selective hearing, self-inflicted. You heard the microwave from two rooms away but not your name three times.

Run with Node 22+:

```sh
node main.ts
```
